# cobblemon_addon_ghost_pvp

Ghost Pokémon est une couche indépendante de Pokémon virtuels permettant à tout joueur possédant l'addon de créer, importer, modifier, stocker et utiliser des équipes Pokémon personnalisées selon le format Pokémon Showdown/Smogon.

Les Ghost Pokémon sont indépendants des données Pokémon normales de Cobblemon et sont entièrement gérés par le système Ghost.

Lorsque cela est possible, Ghost Pokémon utilise les systèmes natifs de Cobblemon afin de reproduire le comportement d'un Pokémon normal. Lorsque Cobblemon impose une restriction que notre système ne peut pas contourner directement, le backend Ghost prend en charge la logique nécessaire.

Les Ghost Pokémon sont utilisables dans le monde et peuvent être envoyés/présentés comme des Pokémon normaux, mais leurs fonctionnalités sont volontairement limitées au cadre défini par Ghost Pokémon, principalement le PvP entre joueurs possédant l'addon.
